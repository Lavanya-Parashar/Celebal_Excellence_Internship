# Azure Cloud Fundamentals and Data Pipeline Implementation using Azure Data Factory

## Objective
To build an end-to-end data pipeline using Azure Blob Storage and Azure Data Factory.

## Files Included
- Week4_Assignment.pdf
- Superstore_copy.csv

## Technologies Used
- Azure Resource Group
- Azure Storage Account
- Azure Blob Storage
- Azure Data Factory
- Linked Services
- Datasets
- Get Metadata Activity
- Copy Data Activity
- IAM Roles

## Result
The pipeline successfully validated metadata and copied Superstore.csv from the source container to the processed container as Superstore_copy.csv.
